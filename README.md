# Rocket Movies

Aplicação de front-end (React + Vite) para cadastro e avaliação de filmes assistidos, com autenticação (sign in/sign up), perfil de usuário, listagem, busca e criação de fichas de filme. Feito durante a trilha de React da Rocketseat, consumindo uma API REST fornecida pelo curso.

## Stack

- React 18, React Router, styled-components, axios

## Rodando localmente

\`\`\`bash
npm install
npm run dev
\`\`\`

Requer a API do curso rodando localmente (não incluída neste repositório).

Exercício de curso — Rocketseat (trilha React).
